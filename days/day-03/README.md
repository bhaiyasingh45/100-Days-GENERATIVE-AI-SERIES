# Day 03 — What is Generative AI?

## Title
**Generative AI Series #03 — What is Generative AI?**

## Topic
Understanding Generative AI and how it differs from traditional AI.

## Learning objective
Understand Generative AI as a class of AI systems that can generate new content such as text, images, audio, video, code, and other outputs by learning patterns from data.

## Instagram caption
🧠 **GENERATIVE AI SERIES #03 — What is Generative AI?**

We’ve covered **AI, Machine Learning, and Deep Learning**. Now let’s understand the technology behind the AI revolution — **Generative AI.** 🚀

Generative AI is a type of AI that can **create new content** such as:

✍️ Text  
🎨 Images  
🎵 Music  
🎬 Videos  
💻 Code  
🧊 3D models & designs

Unlike traditional AI, which commonly analyzes existing data, detects patterns, makes predictions, classifies information, or supports decisions, Generative AI learns patterns from data and uses them to generate new outputs.

A simplified view:

**Training Data → Pattern Learning → Generative Model → Prompt → Generated Output**

💡 **Key takeaway:**  
Generative AI doesn't just analyze the world — it can **create new possibilities** from what it has learned.
