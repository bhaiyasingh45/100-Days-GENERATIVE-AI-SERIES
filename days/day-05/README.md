# Day 05 — How Does Generative AI Work?

## Title
**Generative AI Series #05 — How Does Generative AI Work?**

## Topic
A high-level view of how generative AI models learn patterns from data and generate new outputs from prompts.

## Learning objective
Understand the basic lifecycle: training data → model training → learned parameters → prompt/input → inference → generated output. This is a simplified conceptual view; different generative models use different architectures and generation mechanisms.

## Instagram caption
🧠 **GENERATIVE AI SERIES #05 — How Does Generative AI Work?**

We know what Generative AI is. But **how does it actually create new content?** 🤔

At a high level, the process looks like:

📚 **Training Data** → 🧠 **Model Training** → 🔷 **Learned Model** → 💬 **Prompt** → ⚙️ **Inference** → ✨ **Generated Output**

A generative AI model learns patterns and relationships from large datasets. When you provide an input or prompt, the trained model uses those learned representations to generate an output according to the model's architecture and generation process.

For an LLM, generation commonly happens by predicting tokens sequentially, while other generative models use different mechanisms.

💡 **Key takeaway:**
Generative AI models learn patterns from data and use those learned patterns to generate new outputs.
